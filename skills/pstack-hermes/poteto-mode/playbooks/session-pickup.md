### Session pickup

**You own the resume point. Read the prior trail, don't redo it.** Prior decisions are context. Prior success claims still need evidence.

1. Locate the exact authorized prior trail. It may be a resume note, decision log, named Hermes session, relevant exported transcript, PR, or pushed branch. Hermes history is profile-local and canonically in `$HERMES_HOME/state.db`, not an assumed workspace transcript directory. Use an available `session_search` for that session or inspect `terminal(command='hermes sessions list --help')` and `terminal(command='hermes sessions export --help')` before using the installed CLI. Do not scan other profiles or unrelated chats. Read metadata and last messages first, then decision points. For a large provided export, use a bounded read-only `delegate_task(tasks=[{'goal': '<reduced timeline>', 'context': '<exact authorized export, decisions, done/pending, evidence pointers, no writes>'}])` when available. Children inherit the parent model and have isolated contexts. Verify their pointers and keep only the reduced timeline. Load `skill_view(name='principle-guard-the-context-window')`.
2. Reconstruct operational state through `terminal`, `read_file`, and `search_files`. Check branch/worktree, history and diff against the actual base, PR heads, running terminal jobs, open todos, decisions, and authorization. Distinguish reported, observed, and stale state. Do not infer a running agent from a transcript timestamp or assume a delegated child survived its parent.
3. Diff done versus pending. Compare shipped artifacts with the original goal and plan and name the resume point. Preserve settled decisions and avoid replaying completed exploration. Re-run a narrow check only when evidence is missing, the artifact changed, or the current claim matters to the next action. A broad from-scratch pass wastes the inherited trail; blind trust in a summary is equally wrong.
4. Route the remainder to the matching playbook with `skill_view(name='poteto-mode', file_path='playbooks/<selected-playbook>.md')`. Choose whether to continue execution, ship a finished recommendation, ratify or override a conclusion, or postmortem a failed run. The routed playbook owns the rest, within the current user's grant.
5. Load `skill_view(name='principle-prove-it-works')`. Verify inherited completion claims against the original goal on the real artifact before saying done. A passing self-report or child summary is not proof. Record the exact evidence you reused and any check you had to repeat.

**Reply:** where the prior agent stopped, inherited versus redone work, resume point, verified current state, outcome, and any missing access or evidence.
