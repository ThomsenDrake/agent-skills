### Worktree and simulator cleanup

This playbook can delete user state without a code review. Its evidence and authorization gates are the review. A cleanup request is not permission to delete unknown files, chat history, credentials, or another profile's data.

1. **Snapshot and enumerate.** Use `terminal` to record disk usage, then `terminal(command='git worktree list --porcelain', workdir='<repo>')` as the authoritative path list. Never invent worktree paths from naming conventions. Discover the actual base ref and inspect each enumerated path for size, branch/head, merge relation, tracked changes, untracked/ignored files, remote tip, and PR state. Use the active forge, `gh` by default, and account for squash merges with the PR's merged state and commit evidence rather than ancestry alone. Parse paths safely and quote every path. Check freshness before trusting a remote merge result.
2. **Do not rely on an unported audit helper.** Skip the preserved `scripts/worktree-audit.sh` on Hermes. It scans editor transcripts and uses macOS-specific `stat`/`date`, so its heuristic buckets cannot establish safe ownership or deletion. The native workflow is the worktree enumeration plus explicit per-path checks above. `skill_view(name='principle-build-the-lever')` may guide an authorized replacement; this cleanup does not require changing the bundled script.
3. **Establish the active set.** Get the user's in-use and pinned session/worktree set, known worker ownership, running servers, and program store. An active Hermes profile's session records or an available session tool may provide supporting evidence, but no sidebar or transcript mtime proves a worktree is idle. Do not scan other profiles or unrelated chats. If the active set cannot be established, hold candidates whose ownership is uncertain. A clean merged tree can still be in use.
4. **Verify each doubtful candidate.** Inspect only the relevant authorized session export or branch/run receipts. Large exports may use `delegate_task(tasks=[{'goal': '<read-only ownership audit>', 'context': '<exact export and candidate paths, no writes, evidence citations>'}])` if available. Children inherit the parent model and have isolated contexts. Verify the report yourself. Do independent work and end the turn for result delivery, not transcript polling. An agent may own sibling scratch or repro trees even when their names are absent from its title.
5. **Pause on loss or uncertainty.** Show tracked diffs and name untracked/ignored files before any removal. Untracked is not synonymous with disposable. Hold uncommitted work, unpushed commits, active jobs, locked worktrees, unclear ownership, and an unverified merge. Delete only the exact clean, merged, not-in-use set covered by the cleanup grant. Ask for a decision or a backup on anything else. Never treat an audit's "safe" label as permission.
6. **Prune the confirmed set.** Prefer `terminal(command='git worktree remove "<enumerated path>"', workdir='<repo>')` without force. If it refuses, investigate rather than retrying with force. Ignored build artifacts or locks require a separately checked and authorized path-specific removal; no blanket recursive delete. Branch refs should survive. Then run `terminal(command='git worktree prune', workdir='<repo>')`, re-enumerate, and record disk usage again. Compute reclaimed space with a tool and account for every removed or retained path.
7. **Other reclaimers are optional and platform-gated.** On macOS only, inspect `terminal(command='xcrun simctl list')` and runtime usage before proposing unavailable simulators or old runtimes for deletion. Deleting testing-device clones, Xcode DerivedData, device support, or package caches needs an explicit exact set and the same in-use and loss checks. Discover cache commands for the installed pnpm, uv, brew, or yarn version rather than deleting guessed folders. On other hosts, skip simulator steps. Never clear Hermes state, skills, sessions, memories, or another profile to save space without a separate specific grant.

**Reply:** before/after disk usage, tool-computed space reclaimed, exact worktrees removed, and a one-line evidence-based reason for each held path. State any skipped helper or platform-specific step.
